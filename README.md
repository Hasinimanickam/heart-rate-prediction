# ❤️ Heart Rate AI

### Machine Learning Based Maximum Heart Rate Prediction

Heart Rate AI is a machine learning web application that predicts a user's estimated maximum heart rate during exercise based on basic health and lifestyle inputs.

## 🚀 Features

- ❤️ Maximum heart rate prediction
- 👤 Age-based input
- 😴 Sleep hours input
- 🏃 Exercise frequency input
- 💓 Resting heart rate inputs
- 🤖 Machine learning based prediction
- 🎨 Interactive Streamlit web interface
- ✨ Animated and responsive UI

## 🛠️ Technologies Used

- Python
- Streamlit
- Pandas
- Scikit-learn
- Joblib

## 📊 Machine Learning Model

The application uses a **Gradient Boosting Regressor** to estimate maximum heart rate.

### Input Features

- Age
- Sleep Hours
- Exercise Frequency
- Resting Heart Rate Before
- Resting Heart Rate After

### Target

- Maximum Heart Rate During Exercise
